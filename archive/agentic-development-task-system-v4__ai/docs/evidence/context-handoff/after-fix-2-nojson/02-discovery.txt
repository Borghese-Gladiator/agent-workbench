# Task Brief: Add `divide(a, b)` to the calc library

## Request Summary

Add a `divide(a, b)` function to `src/calc.js` that performs division and throws a descriptive error when the divisor is zero. The function must follow the same code style (naming, error pattern, export mechanism) as the existing arithmetic functions already in the file.

---

## Scope

**In scope:**
- Add `divide(a, b)` to `src/calc.js`
- Throw an `Error` with a clear message when `b === 0`
- Export the function using the same pattern as existing functions
- Match existing style: indentation, naming conventions, function form (declaration vs expression vs arrow)

**Out of scope:**
- Modifying or touching any existing functions
- Input type validation (e.g., rejecting non-numeric arguments) beyond what existing functions already do
- Floating-point precision handling or rounding (e.g., `1/3` returns a repeating decimal as-is)
- Adding tests (not requested; left to a later stage if applicable)
- CLI, REPL, or UI integration
