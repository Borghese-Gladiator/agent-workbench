### Discovery — discovery (claude)

The file is straightforward. Three named exports, each a one-liner arrow-style function declaration (`export function name(a, b) { return ... }`). No default export, no input validation on the existing functions, no test file visible in this directory.

**What to add:** A fourth exported function in the same style, directly after `multiply`:

```js
export function divide(a, b) {
  if (b === 0) throw new Error("Division by zero");
  return a / b;
}
```

**Conventions to follow:**
- Named `export function` declaration (not `const fn = ...`)
- Two parameters `(a, b)`, no type guards beyond the zero check
- Single `return` expression for the happy path
- No JSDoc, no comments (none on existing functions)

**Watch out for:** Using `b === 0` (strict equality) is appropriate here — passing `"0"` or other falsy values will still divide, which matches the permissive style of the existing functions that also do no type validation.
