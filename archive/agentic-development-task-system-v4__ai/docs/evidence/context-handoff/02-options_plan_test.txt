Title: Build a playable tic-tac-toe game

Request:
Build a tic-tac-toe game as a single static web app (index.html + a JS file,
no framework, no build step) that two players can play in the browser:
- A 3x3 grid the players click to place X then O, alternating.
- Detect and announce the winner (or a draw), and offer a reset.
- Use accessible, user-facing markup so a Playwright test can drive it with
  getByRole.

plays a full game to a win in a real browser, with video + trace ON, and
leave the recording as proof.
