# Figma UI Redesign — shadcn/ui + Polished Dark Theme (v0.0.6)

## Brief

Upgrade the existing frontend to match the Figma Make design for the "Agentic-driven Development Dashboard". The Figma design uses a polished shadcn/ui-style component library with Radix UI primitives, Tailwind CSS theme variables, proper dark mode, and a refined layout with a top header bar + left sidebar. The current frontend is functional but uses raw Tailwind utility classes with hardcoded gray-900/950 colors and basic HTML elements (plain `<select>`, `<button>`, etc.).

**Key design differences:**
1. **Layout**: Figma has a top header bar (black, with "Agentic Dev" branding + Zap icon) + left sidebar underneath. Current has only a left sidebar with text links.
2. **Design system**: Figma uses CSS custom properties (`--border`, `--background`, `--muted-foreground`, etc.) with a proper dark theme. Current uses hardcoded Tailwind gray-NNN classes.
3. **Components**: Figma uses shadcn/ui-style components (Badge, Button, Select, Dialog, Card, etc.) built on Radix UI. Current uses raw HTML elements.
4. **Status badges**: Figma uses semi-transparent colored badges (`bg-emerald-500/10 text-emerald-500 border-emerald-500/20`). Current uses solid opaque badges (`bg-green-900 text-green-300`).
5. **Icons**: Figma uses `lucide-react` icons throughout. Current uses no icons.
6. **Pages**: Figma has a proper Terminal page with session list + terminal output. Current has a placeholder. Figma doesn't have an Ingest page (keep existing).
7. **Detail pages**: Figma uses bordered card sections with icons for metadata. Current uses flat text sections.

## Strategy

Install shadcn/ui and use its components directly — the Figma design is built with them, so this gives us an exact match with minimal custom code. shadcn/ui components are copied into the project (not a library dependency), so we own the code and can customize as needed.

- Install shadcn/ui via `npx shadcn@latest init` + add the specific components we need
- This brings in Radix UI primitives, `class-variance-authority`, `clsx`, `tailwind-merge`, and `lucide-react` automatically
- Add the CSS theme variables from the Figma design (shadcn init will scaffold most of this)
- Keep React Query hooks and real API integration (don't switch to mock data)
- Keep react-router-dom (not react-router v7 like the Figma uses)

## Changes

### Phase 1: Foundation (shadcn/ui + CSS theme + layout)

**1.1 Initialize shadcn/ui**
- Run `npx shadcn@latest init` — select New York style, dark theme, CSS variables
- This creates: `components.json`, `src/client/lib/utils.ts` (cn helper), and updates `index.css` with theme variables
- Verify the generated CSS variables match the Figma theme; adjust if needed to match the Figma `theme.css` (dark mode oklch values, sidebar variables, etc.)

**1.2 Install shadcn/ui components**
- Run `npx shadcn@latest add badge button select dialog input textarea label separator`
- These get installed to `src/client/components/ui/` (configure path in `components.json`)
- Also install `lucide-react` if not pulled in automatically

**1.3 Update CSS theme**
- File: `src/client/index.css`
- Ensure the `.dark` class variables match the Figma design exactly: `--background`, `--foreground`, `--border`, `--muted`, `--muted-foreground`, `--accent`, `--card`, `--destructive`, `--ring`, `--sidebar-*`
- Add `@theme inline` block mapping CSS vars to Tailwind `--color-*` tokens
- Add base layer styles for typography (h1-h4) from the Figma `theme.css`

**1.4 Redesign App layout**
- File: `src/client/App.tsx`
- Add top header bar: black background, Zap icon + "Agentic Dev" mono text
- Restructure to header → (sidebar + content) layout
- Sidebar: icons per nav item (FileText, CheckSquare, Terminal, Activity, Upload for Ingest), active state with `bg-accent` highlight, rounded-lg links
- Add sidebar footer with stats (Active Tasks, Draft Issues, Running Sessions) — can be static initially
- Add `dark` class to root element for theme

**1.5 Update main container**
- Remove `p-6` padding from `<main>` (each page controls its own padding now via header + content areas)
- Use `overflow-hidden` on main, let each page handle scrolling
