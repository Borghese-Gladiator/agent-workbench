# v0.1.1 — Top Tabs Navigation

## Brief

Replace the left sidebar navigation with a horizontal tab bar integrated into the top header. This matches the reference UI where the brand logo and navigation tabs share a single top bar, freeing up horizontal space for content.

---

## Reference UI

From the screenshot:
- Single top bar with: logo ("Agentic-Driven Development" + icon) on the left, then horizontal tabs (Issues, Tasks, Terminal, Activity) inline
- No sidebar — the full window width is available for page content
- Active tab is visually distinct (underline or highlight)
- Right side of the header has an "Activity" section/indicator

## Addendum: v0.1.1 Chore Fixes & Board Redesign

### Chore fixes

1. **Top tabs: center and bigger font** — Center the tab labels in the header bar and increase font size to `text-xl` (1.25rem) for better visual weight.

2. **Remove "status" filter** from the Board filter bar — status is already implicit in the kanban columns.

3. **Remove "agent" filter** from the Board filter bar — agents are background actors, not a useful filter.

4. **Default group-by to "epic"** — `groupBy` state initializes to `'epic'` instead of `'none'`.

5. **Consolidate "Group by" dropdown** — Since "Group by epic" and "No grouping" are the only two options, replace the dropdown with a simple toggle button. When `groupBy === 'epic'`, show flat columns; when `groupBy === 'none'`, show the grouped view. This removes the unnecessary `<Select>`.

6. **Tasks view: hide caret when no plans** — In `LibraryPage`, the `TreeWorkItem` component should only render the expand chevron if the work item has plan artifacts. Items with no plans show no caret and are not expandable.

7. **Tasks view: clickable title/icon opens ticket** — In `LibraryPage > WorkItemPreview`, wrapping the `KindIcon` + title in a `<Link to="/work-items/:id">` so clicking them navigates to the full ticket detail page.

8. **Board drawer: title/icon opens ticket, remove "Open ticket" link** — In `WorkItemDrawer`, wrap the `KindIcon` + title in a clickable link to `/work-items/:id`. Remove the separate "Open ticket" button from the drawer header.

### Bigger fix: Board epic grouping redesign

The board's "group by epic" layout should match Linear's approach:

**Before:** Each epic gets its own set of 5 column containers side by side (duplicated column headers per epic).

**After (Linear-style):**
- **Column headers** render once at the top as a fixed row spanning full width
- Below the headers, **each epic is a collapsible row** with a chevron + epic icon + title + item count
- When expanded, the epic row contains its cards placed in a CSS grid aligned to the column headers above
- Cards sit under the correct column based on their status
- Collapsing an epic hides all its cards

```
┌──────────┬──────────┬──────────┬──────────┬──────────┐
│  Triage  │  Ready   │ In Prog  │  Review  │   Done   │  ← column headers (once)
├──────────┴──────────┴──────────┴──────────┴──────────┤
│ ▼ 🎯 Epic A                                   3/10  │  ← collapsible epic row
│   [card]   [card]     [card]                         │  ← cards in grid columns
│            [card]                                    │
├──────────────────────────────────────────────────────┤
│ ▼ 🐛 Epic B                                   1/5   │
│                       [card]                         │
├──────────────────────────────────────────────────────┤
│ ▶ Ungrouped                                    2    │  ← collapsed
└──────────────────────────────────────────────────────┘
```

## Addendum 3: Column Gaps, Card Layout, Status Icons, Full-Width Columns

### 1. Proper column gap (not border, not 1px)

The column separators in the epic-grouped board should be real visible gaps (~4-6px) where the page background shows through between column areas — not thin borders. The grid wrapper background serves as the "gap color" and each column cell has an opaque card background. Change from `gap-1 bg-border/40` to a proper gap that clearly separates the columns visually.

### 2. Columns fill available screen width

Currently columns use a fixed `15rem` width. Change to `1fr` so columns stretch to fill the entire viewport width. The grid should use `minmax(0, 1fr)` for each column. This applies to both the column header row and the card grid rows.

### 3. Colored status dot icons on column headers

Each column header gets a small colored circle/dot matching its status color (from `StatusBadge` color map):
- Triage: gray dot
- Ready: cyan dot
- In Progress: blue dot
- Review: purple dot
- Done: emerald dot

Placed inline before the column label text.

### 4. Short ID on cards

Each card shows a truncated ID (first 8 chars of UUID) in smaller muted text at the top-left of the card, above the title. Similar to how Linear shows `CORE-349` — we show `#a1b2c3d4`.

### 5. Swap card footer: created date left, agent right

Currently: agent left, time-ago right. Swap to: created date (left), assigned agent (right). Matches the Linear card layout where the creation date is at the bottom-left.
